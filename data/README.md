# Data Description

## Original Dataset

The original project used survey and spatial data
provided by Geodesignhub.

Input files:

- survey_responses.csv
- downloaded_data_polygons.gpkg

The two datasets are linked using a unique ID.

## Data Types

- Survey responses
- Planning categories
- Citizen-drawn spatial geometries
- Geographical information

## Data Availability

The original industry dataset is not included in
this repository.

Access and redistribution are subject to the relevant
data-sharing permissions.

## Synthetic Data

A synthetic dataset is planned for public testing
and methodological demonstrations.

Synthetic data must not be interpreted as the
original survey dataset.
